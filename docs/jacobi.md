# jacobi: Kronecker and Jacobi symbols and the least square root modulo a prime

Code: `core/jacobi/jacobi.cpp` (contract in `core/jacobi/jacobi.h`). Tests: `tests/jacobi/jacobi_tests.cpp`. Reference: `tools/jacobi_ref.py`. Evidence label: unit tests only.

## Rule

- `kronecker(a, n)` for every i64 a and every u32 n (n = 0 included) gives the Kronecker symbol in {-1, 0, 1}; it fails only for a null `out`. `jacobi(a, n)` gives the same value for an odd n; an even n, 0 included, is BadModulus. `sqrt_mod_prime(a, p)` gives the least x in [0, p) with x * x = a modulo p for a prime p below 2^32; a p that is 0, 1 or composite is NotPrime, a nonzero residue that is not a square is NoRoot.
- Check order, every function: a null `out` is NullArgument; then the function-specific failure (even n for `jacobi`; the prime test, then the Euler test, for `sqrt_mod_prime`). Nothing is written to `*out` on a failure.
- Pure integer. No tables, arrays, allocation, recursion, mutable statics, 128-bit types, builtins or intrinsics in the implementation. The only product modulo p is `mul(a, b, p) = (a * b) % p` on u64.

## Method

- `symbol(a, n)`: n = 0 gives 1 for a = 1 or -1, else 0. Otherwise n = 2^v m with m odd (v by shifting). For v at least 1: an even a gives 0, and for an odd v with `a & 7` equal to 3 or 5 the sign is -1 (`a & 7` of the two's complement value is the mathematical residue of a modulo 8). For m = 1 the result is the sign. Otherwise a is reduced into [0, m) (i64 `%` then a correction; m at least 3 so there is no overflow, also for the most negative a), and with x = a mod m, y = m the loop runs: while x is nonzero, strip the factors 2 from x (each flips the sign when y is 3 or 5 modulo 8), swap x and y, flip the sign when both are 3 modulo 4, x = x mod y. At the end the result is the sign when y = 1, else 0.
- `kronecker` and `jacobi` call `symbol` after their checks. Cost: O(log n) (below).
- `sqrt_mod_prime`: null check; primality by trial division (2, 3, then 6k - 1 and 6k + 1 while d * d <= p; O(sqrt p)); r = a mod p in [0, p). p = 2 gives x = r. For a nonzero r: the Euler test r^((p-1)/2) must be 1, else NoRoot; for p = 3 modulo 4, x = r^((p+1)/4); otherwise Tonelli-Shanks. The result is min(x, p - x). A zero residue gives 0.
- Tonelli-Shanks: p - 1 = q 2^s with q odd; z the least non-residue found by trying 2, 3, ... with the Euler test; c = z^q, t = r^q, x = r^((q+1)/2), m = s. While t is not 1: i is the least number with t^(2^i) = 1 (by squaring), b = c squared m - i - 1 times, x = x b, c = b b, t = t c, m = i.

## Proofs

**Multiplicativity and the 2-adic step.** By definition (a / n) is the product of the symbols of the prime factors of n with multiplicity, so (a / 2^v m) = (a / 2)^v (a / m) for odd m, with (a / 2) = 0 for even a, 1 for a = 1, 7 and -1 for a = 3, 5 modulo 8. For m = 1 the symbol (a / 1) is 1. For n = 0 the definition (given in the header) is used directly.

**Reduction of a, and gcd above 1.** For an odd m the Jacobi symbol depends on a modulo m only (each Legendre factor does), so the floor-mod reduction is exact. If gcd(a, m) > 1 some prime factor of m divides a, the symbol is 0.

**The reciprocity loop.** The loop keeps the value of sign * (x / y) for odd positive y. Stripping a factor 2 from x uses (2 / y) = -1 exactly when y is 3 or 5 modulo 8. When x is odd and positive the law of quadratic reciprocity for the Jacobi symbol gives (x / y) = (y / x) * (-1)^((x-1)(y-1)/4), so the swap flips the sign exactly when both are 3 modulo 4. Then (y / x) = ((y mod x) / x). When x reaches 0 the symbol (0 / y) is 1 for y = 1 and 0 otherwise, and y is then gcd(a mod m, m). Termination: after the strip x is odd, after the swap and the reduction the new x is below the new y and the pair is a Euclid step (x, y) to (y mod x, x) up to the shifts, so the number of rounds is O(log m); the shifts take at most 32 steps in all (each halves x).

**Prime test.** A composite below 2^32 has a prime factor of at most 65535. Every prime above 3 is 6k - 1 or 6k + 1, so d and d + 2 with d = 5, 11, 17, ... cover them. The u64 product d * d does not wrap; the loop runs at most about 10923 times. The candidate d + 2 never equals p (the loop is entered only for p at least 25).

**Euler and the root for p = 3 modulo 4.** For a nonzero r, r^((p-1)/2) is 1 for a square and -1 otherwise. For p = 3 modulo 4 and x = r^((p+1)/4): x^2 = r^((p+1)/2) = r * r^((p-1)/2) = r.

**Tonelli-Shanks.** Invariants at the loop head: x^2 = r t; the order of t divides 2^(m-1); c has order exactly 2^m. At the start: x^2 = r^(q+1) = r t; t^(2^(s-1)) = r^((p-1)/2) = 1; c^(2^(s-1)) = z^((p-1)/2) = -1, so c has order 2^s, m = s. In a round, i is the least with t^(2^i) = 1, so i < m, and t^(2^(i-1)) = -1 (for i at least 1). b = c^(2^(m-i-1)) has order 2^(i+1), so b^(2^i) = -1 and the new c = b^2 has order 2^i. The new x = x b has x^2 b^2 = r t c, the new t = t c, and (t c)^(2^(i-1)) = (-1)(-1) = 1, so the order of the new t divides 2^(i-1) = 2^(m'-1) with m' = i. The code squares b for j with j + 1 + i < m, which is m - i - 1 times. m strictly decreases, so there are at most s <= 31 rounds, each with at most 31 squarings. When t = 1, x^2 = r.

**The least root.** For an odd prime p and r nonzero the two roots are x and p - x, different; min picks the least. For r = 0 the root is 0. For p = 2 the root is r.

**The product bound.** Every operand of `mul` is a residue below p (r, c, t, x, b, z are all reduced; z is below p by the next proof), and p < 2^32, so a product is at most (p - 1)^2 <= (2^32 - 2)^2 < 2^64.

**The non-residue search.** Let n be the least non-residue modulo an odd prime p. Every number from 1 to n - 1 is a residue. Let m = ceil(p / n), so m n - p is in [0, n - 1]; it is not 0 since n < p and p is prime, so it is a residue. Then (m / p)(n / p) = ((m n - p) / p) = 1, so m is a non-residue and m >= n. So n^2 <= m n < p + n, that is n (n - 1) < p, so n < sqrt(p) + 1. This is a proof: the search tries at most sqrt(p) + 1 candidates; it is polylogarithmic only under the generalized Riemann hypothesis (not proved). **Measurement, not a proof:** the least non-residue was computed for every odd prime below 2^32 (203280220 primes; 2 has no non-residue): segmented sieve of the odd numbers in blocks, and for each prime p the least z from 2 upward with z^((p-1)/2) = p - 1 modulo p by a local square and multiply (a separate program outside the repository, gcc -O2, about 109 s of one core in two runs). Largest value over all odd primes: 97, at p = 2929911599 (p = 3 modulo 4, where the library does not search). Largest value over the primes p = 1 modulo 4 (101638380 of them), the case in which the library searches: 83, at p = 898716289. Both are far below sqrt(p) + 1.

## Tests

Expected values come from the header's examples, from test-only oracles of a different method than the library (the symbol by factoring n with trial division and the Euler criterion with a left-to-right power; the square roots by a brute-force residue table for p below 8000 and, above, by the checks x * x = a, the least-root rule and the Euler criterion; primality by Miller-Rabin with the bases 2, 3, 5, 7, 11), from properties, and from FNV-1a 64-bit digests made by `tools/jacobi_ref.py` (Python standard library only: factoring by trial division, Miller-Rabin and Pollard rho, Euler-criterion Legendre symbols; the roots by a brute-force residue table below 8192 and Cipolla above). Properties on the cases of `K2`, `komp` and `K3`: `jacobi` equals `kronecker` for odd n and is BadModulus for even n; multiplicativity in a (the two 32-bit halves of a); periodicity a + n and a - n for odd n; (-1 / n) = (-1)^((n-1)/2); reciprocity for odd n and an odd m made from a; for a prime n the symbol equals the Euler criterion.

## Mutation testing

318 source mutants of `core/jacobi/jacobi.cpp` (script outside the repository), each built with ASan + UBSan against the final tests (md5 above, not edited after the run), abort after the first failure, declaration order, the whole suite per mutant. Mutated: the product, the power (start value, loop test, bit test, both updates, shifts), the prime test (every return, bound, start, step, the two divisors, the width), the symbol (n = 0 and n = 1 cases, the 2-adic strip, the mod 8 table, the floor-mod, the swap, the 3-modulo-4 sign, every loop test, the return, the widths), `kronecker` and `jacobi` (null checks, the even test, the return codes, the argument, the order of the checks, a write on failure), `sqrt_mod_prime` (null and prime checks and their order, the residue, p = 2, the Euler test, the 3-modulo-4 branch and its exponent, q and s, the z search, c, t, x, m, the loop tests, the inner and outer updates, the least-root rule, the output, the return, a write on failure), and 9 cost mutants.

Two runs were concurrent: the first pass ran three builds at a time on one core with a 30 s limit, and the loop probe ran three at a time. The test file was reordered once after a first complete pass (cases moved so the cheap and the check-order cases run first; no case was changed) and the whole set was run again from the start on the final file; only the second pass is counted. Every TIMEOUT, every survivor and every cost mutant of that pass was then rerun alone (one at a time, nothing else running) on the final file: the step-limited group with a 15 s limit (the first 16 of them with 25 s; the suite takes 10.6 s alone), the survivors with a 40 s limit; the cost mutants were built and the whole suite timed alone.

- 197 killed by a failed assertion and 9 killed by an abnormal end (`ip_lt2ret`, `ip_nolt2`, `sy_vloop`, `sy_in_ne`, `k_null_none`, `j_null_ne`, `j_null_none`, `j_aneg`, `s_null_none`: a sanitizer abort or a crash).
- 73 value mutants step-limited, not counted as kills, non-termination not proven (they did not finish in 15 s alone). Probe: each was rebuilt with a counter on every loop that aborts at 200000 trips in one entry; all 73 aborted at the limit (the unmutated library never passes 200000 trips in one loop entry; the trial division runs at most about 10923 trips and the search for z at most sqrt(p) + 1, as proved). The probe shows that the limit was hit, it does not prove non-termination. They are 46 Tonelli-Shanks mutants (q, s, the z test and exponents, c, t, x, m, the loops, the updates), 15 prime-test mutants (start, step, divisors, bound, the final return), 5 symbol mutants (`sy_vsh2`, `sy_xloop2`, `sy_in_sh2`, `sy_mod_sub`, `sy_mod_none`), 4 other `sqrt_mod_prime` mutants (`s_res_lt1`, `s_res_sub`, `s_res_none`, `s_eu_none`), and `mul_u32`, `mul_u32args` and `pw_nobmod`.
- 30 survivors, each equivalent:
  - `ip_dd_p1` (`d * d <= p + 1`): the extra round has d^2 = p + 1, so p is composite and was already found by a smaller prime factor; `ip_pm` (`if (p == d) return false`): d^2 <= p and p at least 25 so d is below p; `ip_step4` (d += 4): d and d + 2 cover every odd number from 5 on (more work, same answer).
  - `sy_nom1` (no `m == 1` return): m = 1 gives r = 0, the loop is not entered and y = 1 returns the sign; `sy_m1le` (`m <= 1`): m is at least 1; `sy_r_le` (`r <= 0`): r = 0 becomes m, x = m, after the swap and reduction x = 0 with y = m, result 0 as before (m > 1 here); `sy_x_u32`, `sy_y_u32` (u32 variables): x and y stay below 2^32; `sy_xloop3` (`x > 0` for `x != 0`): unsigned; `sy_ret_gt` (`y <= 1` for `y == 1`): y is at least 1 at the end.
  - `k_write0` (writes 0 before the result): no failure follows the write. `j_n1` (`n | 1u`): n is odd there.
  - `s_p2_le` (`p <= 2`): p is at least 2 here. `s_p2_none` (the p = 2 branch removed): r = 0 leaves x = 0; r = 1 passes the Euler test, p % 4 = 2 goes to Tonelli-Shanks with q = 1, s = 1, z = 2, t = 1 and x = r. `s_min_le` (`p - x <= x`): equality only for p = 2, x = 1. `s_min_u8` (a reset above 2^32 - 1): x is below p.
  - `s_eu_gt` (`> 1` for `!= 1`): the power of a nonzero residue is never 0; `s_eu_pdiv` (`p / 2` for `(p - 1) / 2`): p is odd there.
  - `s_m3_mod8`, `s_m3_mod8b`, `s_m3_false` (fewer primes take the formula): Tonelli-Shanks is correct for every odd prime and both give the same least root. `s_m3_pw3` (`(p + 3) / 4`): p + 1 is a multiple of 4, so the quotients agree.

  - `s_ts_tgt1` and `s_ts_ttgt` (`> 1` for `!= 1`): t and tt are never 0. `s_ts_jdiff` (`j < m - i - 1` for `j + 1 + i < m`): i < m is an invariant, so there is no wrap.
